## 升级提醒 / Upgrade notes

**破坏性变更：** 移除 `dsh-better-left-sidebar/slots` 类型入口和 `dsh-better-left-sidebar.footer.compact` 公共插槽。第三方插件应移除旧集成；需要继续使用旧协议时，请保留 `0.1.4`。已有时钟、布局和导航偏好仍可使用。

**Breaking change:** the `./slots` type entry and public compact-widget slot are removed. Third-party plugins must remove that integration, or keep using `0.1.4`. Existing clock, layout and navigation preferences remain usable.

## 本版重点 / Highlights

- 保留 DSH 原生整体收起和桌面控制，独立支持导航悬停、点击及触屏展开。
- 内置时钟与余额，可启用、停用和排序。余额默认人民币，设置中可切换美元；优先账号钱包，再尝试已配置的官方 API Key，两者失败时隐藏。
- 修复长金额裁切、极端数值溢出和旧侧栏所有者包装记录未释放的问题。
- 可选显示其他页脚插件的原生紧凑状态，默认关闭。

Native overall collapse remains independent from hover/click/touch navigation. Built-in clock and balance widgets support enablement and ordering. Balance prefers the account wallet, falls back to the configured official API key, and hides when neither is available; select CNY or USD in settings. Long-amount rendering and retired-owner cleanup are fixed. Native compact footer status is optional and off by default.

余额组件会通过 DSH 账号服务或官方 `/user/balance` API 查询数据，凭据保留在服务端。CNY 和 USD 分别记账，不进行汇率换算。详见 README 的隐私与数据说明。

The balance widget queries through DSH's account service or the official balance API, keeping credentials on the Host. CNY and USD are separate wallet balances, not currency conversions. See the README's privacy section.
