# Compatibility

| Item | Value |
| --- | --- |
| Minimum DSH | `0.2.0-rc.2` |
| Target DSH | `0.2.1-rc.3` |
| Supported range | `>=0.2.0-rc.2 <0.2.2-0` |
| Verified DSH | Prior client: `0.2.0-rc.2` and `0.2.1-rc.2` on 2026-10-27; redesigned client: `0.2.1-rc.2` and `0.2.1-rc.3` on 2026-10-28; Native-collapse and footer adaptation: `0.2.1-rc.3` on 2026-11-02; balance, single-currency settings and long-amount rendering: `0.2.1-rc.3` on 2026-11-02 |
| Node.js | `^22.19.0 || >=24.0.0` |
| Profile | `web` |

`0.2.0` retains native overall collapse and the split navigation/conversation layout, uses a private built-in widget collection, and adds account-first balance queries. It removes the public `./slots` type entry and compact-widget slot shipped in `0.1.4`.

## Integration contracts

The client keeps DSH's native sidebar owner and adds a semantic layout adapter, an interaction state owner, and a staged settings form. It does not create a second sidebar or move React-managed nodes.

- **Host admission:** DSH `0.2.1-rc.2` checks `engines.dsh` during installation and checks `peerDependencies` on `@deepseek-ai/dsh` and `@deepseek-ai/dsh-*` before loading, including prereleases. The optional host peer still participates. Keep both declarations on the same bounded range, and keep `config.dshVersion` inside that range as the reproducible development target.
- **Client lifecycle:** `./client` registers a lazy CommonJS factory through `window.__ModuleLoader__.load`. Cordis effects own styles, adapters, observers, listeners, subscriptions and teardown. The client requests `slots`, `locale`, `configForms` and `connection`; the manifest injects `@deepseek-ai/dsh-client-connection` for the native authenticated carrier.
- **Localization:** `@deepseek-ai/dsh-client-locale` supplies Chinese and English dictionaries and follows DSH's active language preference. The plugin registers a typed `zh`/`en` namespace, binds its translated copy to that locale, and updates it live without overriding the user's global language. Localized Plugin Manager titles and descriptions ship as `locale/zh.json` and `locale/en.json` through the package exports.
- **Sidebar ownership and layout:** `@deepseek-ai/dsh-client-ui-sidebar` owns the single `sidebar` slot and declares child seats such as `sidebar.brand.mark`, `sidebar.panellist`, `sidebar.workspaces`, and `sidebar.settings`; it also exposes the root-scoped `sidebar.panellist.actions` list. The slot registry allows one declaration per child seat, so a replacement root cannot safely redeclare them. DSH `0.2.1-rc.3` has no official region-reordering API. The adapter therefore keeps the stock root and its native DOM/slot owners, annotates the direct regions, and positions them with CSS. When actions are registered, the sidebar More launcher renders as a regular `.panelRow` inside `.panelList`; existing panel-row and portaled-menu handling covers it without a version-specific exception. A missing anchor leaves the native layout intact and reports the exact missing region.
- **Built-in widget host:** The private collection in `src/client/compact-widgets.tsx` registers `dsh-better-left-sidebar.widgets` through declaration-aware injection into DSH's `sidebar.footer.action`. The host portals keyed clock and balance boxes into one plugin-owned 56px rail container and adds no DOM to the native footer outlet. The client leaves `react-dom` external to use DSH's renderer. There is no public widget slot or `./slots` export. See [built-in widgets](compact-widgets.md).
- **Widget lifecycle:** `ctx.slots.inject` waits for the native footer declaration and disposes the host registration with its fiber. Built-ins share that one DSH registration rather than separate third-party entries. Temporary or pinned navigation expansion hides the list with `hidden` and `inert` while retaining component instances; native overall collapse suspends the adapter and widgets. Disabled widgets unmount. Polling pauses while inactive or the page is hidden. Empty boxes consume neither height nor a flex gap; height fitting keeps whole boxes in saved order.
- **Native overall collapse:** DSH owns its collapse state, desktop controls and shortcuts. When the sidebar reports `data-sidebar-collapsed=true` or its native collapsed class, the adapter removes its layout markers and suspends interaction/widget activity. Reopening resolves anchors again and restores the saved split layout. The native inner toggle reserves header space only when it has visible geometry; desktop shells may supply an outer titlebar control instead.
- **Opt-in native footer presentation:** `showCompactPluginStatus` is volatile and defaults to false. With tools at `rail-bottom`, an active split layout and compact navigation, `src/client/native-footer-state.ts` adapts only the native sidebar owner's `sidebar.footer.action` render occurrence to `wide:false`. Conversation-bottom tools and other slot calls retain native props. This is an rc.3 compatibility seam over the mutable stored component record, not an official DSH decoration API. It reuses the original owner-bound renderer, footer instances, stores and error boundaries. The wrapper is stable across preference/hover changes; activation or final teardown may remount the sidebar once. Registry refresh prunes retired owner records and restores a component only if this adapter still owns that field; teardown applies the same guard.
- **Balance transport and data:** The Host registers an exact owner-only buffered POST route `/api/betterLeftSidebar/balance` through Connection's Fetch registry. It validates the published Connection request envelope and returns the matching RPC id. The client uses `connection.rpc.call` on `/api`; Connection retains authentication, trust checks and cancellation. The route does not claim Gateway's singleton interceptor or use a separate transport. `deepseekAccount.getBalance` receives DSH version, client locale and timezone offset. Ready recharge and bonus wallets are summed by currency using `big.js`; a missing/failed selected currency falls back to the configured `deepseek-official` provider from `llm.listConfigurableProviders` and redacted `settings.describe`, including its settings namespace/path. `credentials.resolve(credentialRef(...))` resolves the key per request. The effective provider URL includes the launch-environment override and must have the exact official HTTPS origin before credential resolution. The fallback requests only `https://api.deepseek.com/user/balance`, refuses redirects and uses a 10-second timeout. Only source, currency and decimal amount cross to the client; two unavailable sources return null. A true zero remains valid.
- **Balance refresh and display:** Saved `balanceCurrency` selects one independent CNY or USD wallet, without conversion. Visible active widgets refresh immediately and about 60 seconds after each query completes. Inactivity, document hiding, currency changes and teardown clear client timers and abort client requests; the account service owns its own in-flight query timeout. A saved currency change requests fresh data and excludes late results from the previous selection. Long values use localized compact text or decimal scientific notation at 12px; accessible labels retain the exact amount. No unavailable result is replaced by a zero.
- **Version-specific anchors:** `src/client/layout-adapter.ts` is the only module that knows the CSS-module classes. For `0.2.1-rc.3`, it finds the root under `[data-slot="sidebar"]` and anchors the logo row `.hHd-Xa_logoRow`, New Session `.hHd-Xa_newSession`, global panel list `.hHd-Xa_panelList`, conversation/workspace area `.hHd-Xa_regionArea`, and tools/footer area `.hHd-Xa_footArea`. Recheck these names before widening the supported range. DSH exposes no generic stable-ID contribution contract for third-party compact/expanded navigation content, so the redesign positions the existing native regions and does not infer plugin identity from labels or DOM order.
- **Same-root recovery:** A filtered document-root observer rechecks relevant slot/root changes; a child-list observer on the current root detects same-root region replacements. On replacement, the adapter resolves the anchors again, removes plugin markers from stale nodes, rebinds measurement and resize observers to the new anchors, reapplies the current preferences, and refreshes the click toggle’s tools observation without resetting its pinned state. Adaptation resumes when the full set is present. If an anchor is missing, it detaches the layout and leaves DSH's native arrangement intact; restored anchors trigger recovery. Missing anchors are reported in the console.
- **New Session and brand action:** DSH's brand button also invokes `startSession()`, while a separate New Session action exists in the conversation region. The adapter keeps that explicit New Session control in the conversation pane; the brand button is inert when its brand region is in the rail or hidden, and remains actionable only when the brand is in the conversation pane. This prevents hiding or relocating the logo from removing the conversation action.
- **Sidebar width:** `@deepseek-ai/dsh-client-ui-layout` passes the user's sidebar width to the native sidebar root as its `width` prop; the `0.2.1-rc.3` layout accepts 264–420 px and defaults to 280 px. The plugin leaves that width intact, keeps the navigation rail at 56 px, and sizes the conversation/workspace pane to the remaining sidebar width. Expanding the navigation flyout overlays that pane without another layout change. There is no plugin-specific width preference. The footer launcher uses `settings.trigger` in DSH `0.2.0-rc.2` and `settings.launcher` in `0.2.1-rc.2`.
- **Configuration and migration:** DSH's `configForms` service exposes a snapshot, revision-fenced mutation, and subscription. `SettingsFormModel`/`SettingsForm` provide the native staged draft, save, discard, and save-error contract. Preferences store semantic positions, animation, and expansion mode. The legacy `hiddenRegions` field is removed from the schema and ignored rather than translated, since the old values cannot express placement; animation and expansion remain supported. `layoutVersion` records an explicit layout choice, and restoring the default layout changes only the three position fields and that marker. Compact widget order and enablement live in the sibling volatile `compactWidgets` array. The built-in clock face lives in the sibling volatile `clock` object: `hourCycle` is `h23` (default) or `h12`; `monthDay` defaults to true and `weekday` defaults to false, and the two can be combined; a saved exclusive `detail` is read until the next save; `color` is an empty string for the theme primary label, or a `#rrggbb` value that stays fixed when the theme changes. In 12-hour mode the time line remains `HH:mm` and adds `P` or `A`. The accessible text still uses the locale day period. The widget box uses the compact rail's full 56 px width and the widget's own height. The host adds no padding or border. See [Widget box](compact-widgets.md#widget-box). The rail clock changes when the user saves. `showCompactPluginStatus` and `balanceCurrency` are sibling volatile fields; existing clock and navigation preferences retain their meaning.
- **Settings composition:** One native staged form orders content layout, expansion/animation, and built-in widgets. Shared radio rows and DSH Checkbox/Switch controls provide labeled inputs. Clock previews follow drafts; live clock and wallet currency change only after saving. `balanceCurrency` is volatile `CNY` by default or `USD`. The catalog distinguishes clipped, inactive, empty and disabled boxes from unsaved enablement, and exposes ordering controls when multiple built-ins are available. Retired third-party ids are ignored by the catalog.
- **Short-window navigation:** With global navigation placed above conversations, the adapter measures the global-navigation rows and limits their height to the space below New Session and above the conversation-bottom tools/footer. It reserves up to 112 px for conversation content when space permits; the navigation region scrolls independently, and both its height and the reserve clamp at zero under extreme constraints. The calculation uses nonnegative dimensions and does not replace native navigation handlers.
- **Menus and focus:** DSH menus expose `role="menu"`, `aria-haspopup="menu"`, `aria-expanded`, and portaled surfaces. The sidebar More menu is opened by a panel-row launcher contributed through `sidebar.panellist.actions`. The native Escape handler closes the menu and restores focus to its trigger. The adapter tracks only popups opened from navigation triggers (and their nested triggers), leaving unrelated dialogs and menus out of the expanded state. Escape is handled after the native menu has had the first opportunity to close.
- **Interaction:** one controller owns compact, temporary, and pinned states. It handles pointer dwell/close timing, keyboard focus, click-mode pinning, outside close, toggle labeling, and popup lifecycle. Click mode uses a fixed 36×36 px control; hover mode has no substitute control. Both modes respect reduced motion, and animation preferences are soft, fast, or off.
- **Plugin Manager icon:** DSH reads a package-root plugin's top-level `icon` from the exported `package.json`; the path is relative to the package root. This template declares `./icon.svg` and ships it in the npm package. Missing or invalid icons use DSH's default artwork. See the [versioned metadata guide](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.0-rc.2/docs/cookbook/adding-a-package.md).

The pinned development target and version-specific sidebar contracts are `0.2.1-rc.3`.

## Known limitation

At a 567×626 viewport, DSH's native “Standard mode” label can truncate in the main column at the default 280 px sidebar width and at its 264 px minimum. The plugin preserves DSH's native width control so users can choose a wider sidebar when the full label matters.
